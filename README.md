# EGG FIRE

Projeto de jogo Battle Royale offline em terceira pessoa, com foco inicial em Android.

## Tecnologias
A base técnica definida para a implementação 3D é Godot 4, usando:
- GDScript para gameplay e sistemas de jogo;
- C++ para extensões e otimizações nativas quando necessário;
- Godot Shader Language para efeitos e materiais gráficos.

Veja [docs/TECNOLOGIAS.md](docs/TECNOLOGIAS.md) para a decisão técnica e o plano de desenvolvimento.

## Estado do projeto
O APK atualmente disponível é somente uma prévia Android do lobby. O jogo 3D e as partidas ainda precisam ser desenvolvidos.
